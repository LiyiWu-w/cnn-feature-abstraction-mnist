# Visualizing and Quantifying Feature Abstraction in CNNs

A comparative study of feature abstraction in shallow vs. deep CNNs, 
using MNIST as a controlled baseline. Evaluates internal representations 
through feature maps, PCA projections, and silhouette scores.

## Key Finding
Silhouette scores rise from 0.012 (raw pixels) to 0.522 (dense layer), 
providing quantitative evidence that CNN depth corresponds to measurably 
more class-separable representations.
